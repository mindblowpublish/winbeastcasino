# Winbeast Casino — Privacy Policy

Готовая статическая страница для GitHub Pages.

## Содержимое

- `index.html` — страница Privacy Policy на английском. Баннер и стили встроены; дополнительные файлы не нужны.
- `.nojekyll` — отключает обработку страницы Jekyll.

## Публикация

1. Создайте репозиторий на GitHub. Если используете GitHub Free, выберите Public.
2. Распакуйте ZIP и загрузите **содержимое папки `winbeast-privacy` в корень репозитория**. Файл `index.html` должен лежать в корне, а не во вложенной папке. Не загружайте сам ZIP вместо файлов.
3. Сохраните файлы в ветке `main`.
4. Откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Source → Deploy from a branch**.
6. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
7. После завершения публикации откройте адрес, показанный GitHub в разделе Pages. Обычно это `https://USERNAME.github.io/REPOSITORY/`.
8. Проверьте страницу на телефоне и компьютере. Убедитесь, что она открывается без входа в аккаунт.
9. Добавьте опубликованный URL в поле Privacy Policy в Google Play Console и в приложение.

## Перед публикацией

Текст подготовлен по сведениям разработчика: Mindblow Publish, OneSignal и Firebase Cloud Messaging для push-уведомлений. Проверьте фактические настройки SDK, порядок выполнения запросов на удаление данных, сроки хранения и используемые правовые основания. Отображаемая дата обновления — October 11, 2026.

## Обновление

Измените `index.html` и загрузите его поверх существующего файла. GitHub Pages опубликует обновление. Если меняется содержание политики, обновите дату в странице.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
